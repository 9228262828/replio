REPLIO — Home Refill Tracker
Tagline: Restock before you run out.
Package: com.replio.home

Add to pubspec.yaml:

dependencies:
  flutter:
    sdk: flutter
  shared_preferences: ^2.3.2

Included:
- Splash Screen
- Home Dashboard
- My Items
- Add / Edit / Delete Item
- Built-in Categories
- Refill List
- Refill History
- Statistics
- Search and Category Filters
- Quick -1 Use action
- Refilled action with quantity input
- Favorite Items
- Current Quantity
- Minimum Quantity
- Units
- Notes
- Last Refill Date
- Smart Status: Good / Low / Refill Now / Out
- Items Running Low
- Items Stocked
- Refills This Week
- Most Frequently Refilled Items
- Dark Mode
- Privacy Policy
- Terms & Conditions
- Reset All Data
- SharedPreferences JSON persistence

No Firebase
No backend
No login
No ads
No analytics
No API
No image/audio assets required
